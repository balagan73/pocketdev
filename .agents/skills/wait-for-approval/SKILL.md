# Wait for Approval

Before making any change — installing, creating, editing, deleting, restarting, opening PRs, pushing to remote, or any action that affects shared systems — always ask the user for explicit permission first.

Do not act on implied intent. Wait for a clear go-ahead such as "yes", "do it", "go ahead", or "proceed".

**Exception:** If given a clear, direct task ("commit this", "push the branch"), execute it. Only ask for permission on follow-on actions the user didn't explicitly request.
